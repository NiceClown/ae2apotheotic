# Апофеотическая автоматизация AE2

Добро пожаловать в руководство по **AE2 Apotheotic Automation**! Этот аддон напрямую связывает систему автокрафта **Applied Energistics 2** с глубокими механиками прогрессии мода **Apotheosis**.

Вам больше не придётся вручную перебирать самоцветы в шкатулках или варить инфузии у стола зачарований. С помощью специализированного кодировщика шаблонов и умных поставщиков шаблонов ваша МЭ-сеть сможет автоматически улучшать самоцветы по цепочке до Идеальных, дробить их в пыль и изготавливать сложнейшие инфузии по первому клику в терминале.

<br clear="all" />

## Обзор блоков аддона

Аддон добавляет три высокотехнологичных блока, выполненных в строгом промышленном стиле классического Applied Energistics 2:

<Row gap="16">
  <BlockImage id="ae2apotheotic:pattern_encoder" scale="4" />
  <BlockImage id="ae2apotheotic:gem_pattern_provider" scale="4" />
  <BlockImage id="ae2apotheotic:infusion_pattern_provider" scale="4" />
</Row>

* <ItemLink id="ae2apotheotic:pattern_encoder" />: Специализированный терминал для создания шаблонов. Поддерживает три режима кодирования, автоматический расчёт характеристик инфузии и **Shift + Кодировать** для мгновенной генерации всей цепочки улучшения чистоты.
* <ItemLink id="ae2apotheotic:gem_pattern_provider" />: Устанавливается вплотную к **Шкатулке самоцветов** (Gem Case). Обладает компактным интерфейсом с категориями по каждому самоцвету, слотами ступеней (I–V + Пыль) и умной маршрутизацией при Shift-клике.
* <ItemLink id="ae2apotheotic:infusion_pattern_provider" />: Устанавливается вплотную к **Столу зачарования Ворона** (или обычному столу). Автоматически подаёт предметы, лазурит и **в первую очередь забирает жидкий опыт напрямую из МЭ-сети**.
