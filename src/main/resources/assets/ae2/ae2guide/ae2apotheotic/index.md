# Apotheotic AE2 Automation

Welcome to **AE2 Apotheotic Automation**! This addon connects **Applied Energistics 2** autocrafting and ME networks directly to the deep progression mechanics of **Apotheosis**.

Autocrafting complex RPG recipes no longer requires manual table clicking or tedious repetitive inventory management. With specialized pattern encoders and intelligent pattern providers, your ME system can orchestrate complete gem upgrade chains, batch gem crushing, and enchanting table infusions on demand.

<br clear="all" />

## Mod Overview

The addon introduces three high-tier machines designed to match the classic AE2 industrial aesthetic:

<Row gap="16">
  <BlockImage id="ae2apotheotic:pattern_encoder" scale="4" />
  <BlockImage id="ae2apotheotic:gem_pattern_provider" scale="4" />
  <BlockImage id="ae2apotheotic:infusion_pattern_provider" scale="4" />
</Row>

* <ItemLink id="ae2apotheotic:pattern_encoder" />: A dedicated terminal for creating specialized pattern cards. Features three encoding modes, automatic stat calculation for infusion, and **Shift + Encode** for instant full purity upgrade chain generation.
* <ItemLink id="ae2apotheotic:gem_pattern_provider" />: Placed directly next to an Apotheosis **Gem Case**. Features a compact categorized interface per gem type, dedicated tier slots (Tiers I–V + Dust), and automated gem insertion and extraction.
* <ItemLink id="ae2apotheotic:infusion_pattern_provider" />: Placed directly next to a **Raven's Enchanting Table** or standard enchanting table. Seamlessly provides items, lapis, and liquid experience with **direct ME network XP extraction**.
