# Апофеотический кодировщик шаблонов

<Row gap="20">
  <BlockImage id="ae2apotheotic:pattern_encoder" scale="8" />
</Row>

<ItemLink id="ae2apotheotic:pattern_encoder" /> — это центральный терминал планирования и записи рецептов для автокрафта Apotheosis. Стандартные терминалы кодирования AE2 не способны работать со ступенями чистоты самоцветов, вариативными материалами огранки и магическими характеристиками стола зачарований. Кодировщик решает эту задачу, создавая специализированные карты-шаблоны для наших поставщиков.

<br clear="all" />

## Интерфейс кодировщика

Интерфейс блока расширен до 210 пикселей для максимального удобства и отсутствия обрезки текста:

1. **Вкладки режимов (сверху):** Переключение между **Улучшением самоцвета**, **Дроблением в пыль** и **Инфузией на столе**.
2. **Слот образца** (слева): Положите исходный самоцвет или предмет для инфузии.
3. **Слот чистых шаблонов** (снизу слева): Положите стандартные чистые шаблоны AE2 (Blank Pattern).
4. **Слот готового шаблона** (снизу справа): Сюда выдаётся готовая закодированная карта.
5. **Центральная панель управления:** Настройка ступеней чистоты, выбор материалов или характеристик стола, а также кнопка **Кодировать**.

## Режим 1: Улучшение самоцветов (Шкатулка)

Этот режим создаёт шаблоны для повышения чистоты самоцветов в Шкатулке (`2x Самоцвета + Материалы → 1x Самоцвет следующей чистоты`).

1. Положите любой самоцвет в слот образца. Исходная чистота автоматически установится равной чистоте образца.
2. При необходимости отрегулируйте начальную чистоту стрелками `<` и `>`.
3. Если рецепт огранки предлагает выбор материалов (например, *3 Осколка магии* **или** *1 Ветхая ткань*), переключайте вариант кнопками со стрелками под слотами материалов.
4. Нажмите **Кодировать**, чтобы записать <ItemLink id="ae2apotheotic:gem_upgrade_pattern" />.

### Мощная функция: Shift + Кодировать (Цепочка улучшений)

Зажмите клавишу **Shift** и нажмите **Кодировать** — кодировщик автоматически создаст полную непрерывную цепочку шаблонов от текущей ступени вплоть до **Идеальной (Perfect)** чистоты!
* Каждый тир расходует один чистый шаблон из слота и сразу отправляет готовый закодированный шаблон в ваш инвентарь.
* Когда все 5 шаблонов цепочки загружены в <ItemLink id="ae2apotheotic:gem_pattern_provider" />, МЭ-сеть сможет моментально рассчитать, сколько Треснувших кристаллов, пыли и ресурсов нужно для создания Идеального самоцвета по запросу.

<br clear="all" />

## Режим 2: Дробление самоцветов в пыль

Этот режим кодирует шаблоны для измельчения кристаллов в **Пыль самоцветов** (Gem Dust). Наш автокрафт строго гарантирует минимальный порог выхода пыли, соответствующий столу утилизации Apotheosis (`apotheosis:salvaging/gem_dust`):

* **Треснувший (Cracked):** 1 пыль
* **Сколотый (Chipped):** 1 пыль
* **С изъяном (Flawed):** 2 пыли
* **Обычный (Normal):** 3 пыли
* **Безупречный (Flawless):** 4 пыли
* **Идеальный (Perfect):** 5 пыли

### Режимы фильтрации

Переключайте режим фильтра кнопкой по центру:
* **«Только этот самоцвет» (Exact):** Измельчает строго указанный тип и чистоту кристалла.
* **«Любой — <Чистота>»:** Измельчает любой самоцвет выбранной ступени (идеально для утилизации лишних Треснувших кристаллов).
* **«Любой самоцвет»:** Разрешает МЭ-сети дробить любые кристаллы (используйте осторожно, чтобы не переработать ценные камни).

Нажмите **Кодировать** для создания <ItemLink id="ae2apotheotic:gem_crush_pattern" />.

<br clear="all" />

## Режим 3: Инфузия на столе зачарований

Автоматизирует создание предметов инфузии (например, Насыщенное дыхание дракона или усиленные книжные полки):

1. Положите предмет в слот образца.
2. Если для предмета есть несколько рецептов, выберите нужный стрелками вверху.
3. Настройте магические характеристики стола:
   * **Этерна (Eterna)** — сила стола.
   * **Кванта (Quanta)** — вариативность.
   * **Аркана (Arcana)** — редкость.
   * Используйте кнопки `-` и `+` (зажмите **Shift** для шага ±10).
4. **Кнопка «Авто»:** Нажмите **Авто**, чтобы кодировщик автоматически выставил точные минимальные требования рецепта!
5. Интерфейс покажет точную стоимость в жидком опыте.
6. Нажмите **Кодировать** для создания <ItemLink id="ae2apotheotic:infusion_pattern" /> (`Предмет + 3x Лазурит + Опыт → Результат`).
